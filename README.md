# 🔴 Reverse Shell Network Detection & Analysis

> ⚠️ **DISCLAIMER: This project was conducted entirely in a controlled, 
> isolated virtual lab environment. No real systems or networks were targeted. 
> For educational purposes only. Unauthorized use of these techniques is illegal.**

---

## 📌 Project Overview

This project simulates a complete reverse shell attack lifecycle and demonstrates 
how to detect it using network forensic tools. Acting as both attacker and defender, 
I generated reverse shells, captured the traffic, and analyzed packets to identify 
Indicators of Compromise (IOCs).

---

## 🎯 Objectives

- Set up an isolated attacker/victim lab environment
- Generate reverse shells using Netcat and Metasploit
- Capture network traffic using Wireshark
- Analyze TCP streams to identify IOCs
- Document findings in a professional penetration test report

---

## 🛠️ Tools Used

| Tool | Purpose |
|------|---------|
| Kali Linux | Attacker machine |
| Ubuntu Server 22.04 | Victim machine |
| Netcat (nc) | Basic reverse shell |
| Metasploit Framework | Advanced reverse shell handler |
| Wireshark | Network packet capture & analysis |
| VirtualBox | Virtualization platform |
